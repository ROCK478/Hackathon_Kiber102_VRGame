# Hackathon_Kiber102_VRGame
**Цель: за 3 суток разработать VR-игру по адаптации детей с ДЦП. Основная идея в том, что управлеие происходит только поворотом головы и взглядом, вследствии чего выполняются упражнения**
**Дата: Ноябрь 2025**
**Результат: Победа**

## Инструкция пользователя
Игра работает и тестируется в VR-шлеме, но в репозитории представлена версия только для Windows. Находится в соответствующей папке. Перед запуском необходимо зайти в папку VR_Game_Data, распаковать архив в эту же папку. После этого запустить exe файл. 

## Особенности
- Сохранение прогресса
- Управление как в VR шлемом, так и поворотом мыши как имитация
- Уровень футбол, баскетбол и основная сессия упражнений для ребенка с ДЦП
- Соревновательный эффект по количеству набитых мячей
- Озвучка с помощью нейросети
